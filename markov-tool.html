Markov land-change calculator

A tool for exploring Markov models of land change. First, build a transition matrix based on land cover at two different years, then project the landscape into the future.

Steps for creating a transition matrix (P)

Raw Tally Matrix

First, count the number of points that converted from one cover type to another.

Transition Probability Matrix (P)

Next, convert the original tallies into probabilities by dividing each tally by its associated row total. Every row in the new table should sum to 1.

Create an Annual Probability Matrix (P)

It’s generally easier to think about land change modelling in terms of yearly change. This step converts the first P matrix to show the annual probabilities for each transition. Rows must still sum to 1.

Multiply the initial conditions vector (t = 0) by P to project the landscape forward in time.
